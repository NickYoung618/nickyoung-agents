# 第三方资源

本包使用 Lucide 1.8.0 作为界面图标，文件为 `vendor/lucide.min.js`。

完整许可与版权声明保留在 `vendor/LUCIDE-LICENSE.txt`。重新分发图标文件或包含图标的单文件界面时，请一并保留该声明。

六张 PNG 是本次设计中生成的视觉预览；其中的任务、文件、模型选择和检查结果是设计示例，不表示现有项目已经实现或通过了这些检查。


本仓库将图标文件及许可分别放在 `public/lucide.min.js` 和 `public/LUCIDE-LICENSE.txt`。原包的六张设计预览未作为功能证据收入本仓库；`evidence/ui-package/` 是接入后的实际浏览器截图，含明确标注的隔离布局测试。
